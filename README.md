# Random Web Dev Mini Projects

A collection of simple web development mini projects demonstrating HTML, CSS, and JavaScript concepts.

## 🚀 Getting Started

Each project is contained in its own numbered folder. To run any project:

1. Navigate to the project folder
2. Open `index.html` in your web browser
3. Interact with the project as needed

## 🛠️ Technologies Used

- **HTML5** - Structure and content
- **CSS3** - Styling and layouts
- **JavaScript** - Interactivity and logic

## 📖 Learning Objectives

These projects cover fundamental web development concepts including:

- HTML structure and semantics
- CSS styling, selectors, and layouts
- JavaScript functions and DOM manipulation
- Event handling
- Form validation
- Array methods and string manipulation
- Pure CSS interactions (checkboxes for state management)
- Responsive design patterns


**Note:** These are educational projects created for learning purposes. Code may be simplified for demonstration and learning objectives.
